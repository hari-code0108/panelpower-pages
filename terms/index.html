利用規約

PanelPowerをご利用いただく際の条件を定めます。

制定：2026年7月14日／最終改定：2026年8月26日

第1条（適用）

本利用規約（以下「本規約」といいます）は、PanelPower運営者（以下「運営者」といいます）が提供するアプリケーション「PanelPower」（以下「本サービス」といいます）の利用条件を定めるものです。利用者は、本規約に同意したうえで本サービスを利用するものとします。

第2条（本サービス）

本サービスは、パワーリフティング等の競技者およびチーム向けに、PR（自己ベスト）、体重、IPF Points、GL Points、ランキング、Room、リアクション、Activityその他の情報を記録・共有する機能を提供します。

本サービスで表示される指標、順位および集計結果は、入力されたデータと本サービスの計算方法に基づく参考情報です。競技団体が発行する公式記録、順位または資格を証明するものではありません。

2.1 任意の開発応援購入

  1. 本サービスでは、App Storeのアプリ内購入を利用して、運営者の今後の開発を任意で応援できます。
  2. 開発応援購入は消耗型の商品であり、同じ商品を何度でも購入できます。購入の有無や金額による機能、ランキング、Room、表示その他の利用条件の違いはありません。
  3. 「プロテイン」「鶏むね肉」「リストラップ」「クレアチン」等、商品名に含まれる物品は提供されません。
  4. 商品価格、決済、購入履歴および返金の取扱いには、App StoreおよびAppleが定める条件が適用されます。
  5. 開発応援購入は、寄付、募金または税制上の寄附金控除の対象となる支払いとして提供するものではありません。

第3条（アカウント）

  1. 利用者は、Google Sign-InまたはSign in with Appleを使用し、Firebase Authenticationを通じてアカウントを作成・利用します。
  2. 利用者は、自己のアカウントを本人のみで利用し、第三者に利用させてはなりません。
  3. 利用者は、登録情報を正確かつ最新の状態に保つものとします。
  4. 認証に使用するGoogleアカウントまたはApple Accountの管理は、利用者自身の責任で行うものとします。
  5. アカウントの不正利用または第三者による利用が疑われる場合、利用者は速やかに運営者へ連絡するものとします。

第4条（PR記録）

  1. 本サービスは、スクワット、ベンチプレス、デッドリフト等について、PR（自己ベスト）記録のみを登録する仕様です。
  2. 利用者は、通常のトレーニングセット、推定値、未成功の試技または自己ベストではない数値をPRとして登録しないものとします。
  3. 利用者は、重量、種目、用具区分、記録日、体重その他の情報を正確に入力するものとします。
  4. Roomの管理者または権限を持つ利用者は、明らかな誤記、不正な記録またはRoomの運用ルールに反する記録を修正・非表示・削除できる場合があります。
  5. 記録の承認基準および公式記録としての取扱いは、所属団体またはRoomのルールに従うものとし、本サービスが記録の正当性を保証するものではありません。

第5条（ランキング）

  1. ランキングは、PR、体重、性別区分、階級、大会区分、用具区分、IPF Points、GL Points等に基づき算出・表示されます。
  2. 集計方法、対象期間、対象者、表示区分および同順位の扱いは、本サービスまたは各Roomの仕様に従います。
  3. 入力データの誤り、未入力、同期中の状態または計算方法の変更により、順位や指標が変動する場合があります。
  4. 利用者は、ランキングを不正に操作する目的で虚偽のPR・体重・区分を登録し、複数アカウントを利用し、または他の利用者の記録を改ざんしてはなりません。

第6条（Room）

  1. 本サービスでは、Public Room、Private RoomおよびLegacy Roomを利用できます。
  2. Public Roomは、検索または公開一覧の対象となり、Room情報および参加者のプロフィール・競技情報が、本サービス上の公開範囲に応じて他の利用者に表示される場合があります。
  3. Private Roomは、招待、承認その他の参加条件が設定されたRoomです。利用者は、招待情報を無断で第三者へ共有してはなりません。
  4. Legacy Roomは、従来のPanelPowerまたはKioskから引き継いだメンバーおよび競技記録を含むRoomです。アカウント未連携の記録が存在する場合があります。
  5. Roomのホスト、スタッフその他の権限を持つ利用者は、参加承認、メンバー情報、表示区分、記録、Claim Codeその他のRoom運営を管理できる場合があります。
  6. Roomを運営する利用者は、参加者の情報を本サービスの目的に沿って適切に取り扱い、無断で外部へ公開または目的外利用してはなりません。
  7. アカウント削除、退室、権限変更またはRoomの削除により、Roomへのアクセスや表示内容が変更される場合があります。

第7条（Claim Code）

  1. Claim Codeは、Legacy Room等に存在する既存メンバー記録を、当該記録の本人のアカウントへ紐付けるためのコードです。
  2. 利用者は、自分に属する記録についてのみClaim Codeを使用できます。
  3. Claim Codeを受け取った利用者は、第三者への転送、公開、売買または不正取得を行ってはなりません。
  4. Roomのホストまたは権限を持つ利用者は、本人確認に必要な範囲でClaim Codeを発行し、適切な相手にのみ伝えるものとします。
  5. Claim Codeには、有効期限、使用回数または失効状態が設定される場合があります。使用済み、失効済みまたは期限切れのClaim Codeは利用できません。
  6. 誤った紐付けまたは不正利用が疑われる場合、運営者は紐付けの停止、調査、修正または関連機能の制限を行うことがあります。

第8条（Kiosk）

  1. Kioskは、Roomに設置された端末等から、メンバー情報、PR、体重その他の情報を入力・更新するための機能です。
  2. Kioskは、Roomの運営者が許可した利用者のみが、許可された目的および範囲で使用できます。
  3. 利用者は、Kioskの管理画面、端末設定、認証情報または他人の記録へ無断でアクセスしてはなりません。
  4. Kioskから入力された記録は、Roomの記録として保存され、Claim済みの利用者については本人アカウントの記録へ同期または反映される場合があります。
  5. Kioskの利用者およびRoomの運営者は、入力内容を確認し、誤入力を発見した場合は速やかに修正または管理者へ連絡するものとします。

第9条（リアクションおよびActivity）

  1. 利用者は、本サービスの仕様に従い、他の利用者のプロフィールまたはPR等へリアクションを送信できます。
  2. PR更新、Room参加その他の操作は、ActivityとしてRoom内に表示される場合があります。
  3. 嫌がらせ、差別、威圧、なりすまし、スパムその他の不適切な目的でリアクションまたはActivity機能を利用してはなりません。

第12条（アカウント削除）

  1. 利用者は、アプリ内の設定画面からアカウント削除を開始できます。
  2. 削除前には、Google Sign-InまたはSign in with Appleによる再認証が必要です。
  3. ホストを務めるRoomに他のメンバーまたは未処理の参加申請がある場合、利用者は先にホスト権限の譲渡または参加申請の整理を行う必要があります。
  4. アカウント削除により、本人のプロフィール、PR、体重、Room所属、リアクション、Activity、通知、Claim済みLegacy記録、Claim CodeおよびFirebase Authenticationのアカウント等が削除されます。
  5. Legacy Roomそのもの、他のメンバーおよび他の利用者のデータは、本人のアカウント削除によって削除されません。本人だけが所属するRoomは、本サービスの仕様に従い削除される場合があります。
  6. 削除処理は段階的に行われ、アプリを閉じた後もサーバー側で継続または再試行される場合があります。
  7. Sign in with Appleを利用している場合、削除時にAppleで再認証し、サーバー側でAppleとの認証連携を取り消します。取り消しに失敗した場合、本人データの削除を開始しないことがあります。
  8. 削除が完了したデータおよびアカウントは、原則として復元できません。

削除対象の詳細は、プライバシーポリシーをご確認ください。
